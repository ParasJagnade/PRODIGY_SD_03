# Task-03: Simple Contact Management System

## Description
This Java console-based application allows users to store and manage contact information such as name, phone number, and email.

## Features
- Add new contacts
- View contact list
- Edit existing contacts
- Delete contacts
- Stores data in memory using ArrayList

## Technologies Used
- Java
- Scanner
- ArrayList

## How to Run
1. Open the project in IntelliJ IDEA or any Java IDE
2. Run ContactManagementSystem.java
3. Follow the on-screen menu options
